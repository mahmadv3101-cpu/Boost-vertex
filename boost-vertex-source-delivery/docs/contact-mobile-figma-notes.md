# Contact Mobile Figma Inspection Notes

## Overall Composition

The supplied mobile Contact frame is a narrow long-form layout with the same dark technical system language as desktop. It uses a compact shared header and a short centered Contact Us hero, then stacks all desktop columns into one vertical evidence flow. The visible sequence is: hero; Drop A Message copy and contact channels; System Initialization form; Let’s Talk Status with three vertical cards; Protocol: Next Steps with three vertical milestones; Global Operations Center; and a dense contact/footer block.

The mobile artboard confirms that Contact should not retain the desktop two-column intake, three-card row, or horizontal protocol line at the narrow breakpoint. Detailed mobile dimensions, text hierarchy, and fixed action treatment will be recorded after focused top-to-bottom inspection.

## Header, Hero, Message, and Form

The mobile header is a compact black bar with **BOOST VERTEX** in electric lime on the left and a small lime hamburger on the right. It has no desktop phone number or Book a Call button. The hero is short and uses a dark, faintly schematic/technical background with centered **Contact Us** display text.

Below the hero, the page begins with **Drop A Message**. The mobile reference uses a single concise paragraph: **“Email us with any questions or inquiries or call 0304-3444-825. We would be happy to answer your question and set up a meeting with you.”** The desktop explanatory paragraph pair and the two Growth Strategy/Technical Support cards are omitted.

The **System Initialization** panel is a compact single-column card with a thin lime top edge, dark filled fields, a short textarea, and a full-width lime **SEND** button. The privacy note is reduced to **“Our Experts Will Contact You Within 24 Hours.”** The form begins immediately after the message copy and ends immediately before the centered Let’s Talk Status heading.

## Status Cards

**Let’s Talk Status** remains centered with the same lime **STAY CONNECTED WITH US** label, but the cards become tall full-width panels with generous vertical gaps. Their verified mobile order is **MAIL FOR INFORMATION / info@boostvertex.com**, **SECURE LINE / 1-800-VERTEX-9**, then **HEADQUARTERS / Data Center Alpha / Silicon Valley, CA 94025**. The cards use their existing envelope, phone, and map-pin circle icons.

## Protocol: Next Steps

The protocol changes from desktop’s horizontal system line to a clean vertical stack under a left-aligned **Protocol: Next Steps** heading and divider. Each step has a compact outlined/lime icon circle, a bold numbered title, and a short description. The confirmed sequence is: **01. Data Review** (“Our analysts parse your initial submission against our performance benchmarks within 24 hours.”); **02. Alignment Call** (“A 30-minute high-density strategic briefing to confirm viability and scope.”); and **03. Growth Plan** (“Deployment of a custom, phased tactical architecture designed for immediate impact.”).

## Operations and Footer

The Global Operations Center remains above the footer as a separated, quiet dark panel. On mobile it is much taller and simpler than the desktop version: a centered muted globe, uppercase **GLOBAL OPERATIONS CENTER** label, and a restrained two-line status message. The panel shares a visible top divider with the protocol section and a bottom divider with the footer.

The mobile footer starts with a lime **Boost Vertex** wordmark, concise company statement, and compact two-column navigation groups. It is part of the scrolling document. No Contact-specific floating Fast Track action rail is visible in the supplied Contact mobile reference, so the implementation should not add one merely because it appears on other mobile page designs.

## Supplied Refinement References

The later supplied Fast Track reference overrides the earlier absence note. It shows a fixed full-width bottom rail with four equal actions in this order: **CALL**, **CHAT**, **BOOK**, and **INQUIRY**. Each action has a large pale-lime line icon, bold uppercase white label, dark graphite surface, a thin lime top rule, and generous horizontal spacing. The rail must reserve document space on mobile so it never covers the footer or form controls.

The later supplied Contact mobile hero reference also confirms that the hero must use a dim technical-network background image with a dark overlay behind the centered white **Contact Us** display title. The image is mobile-only and the approved desktop hero remains unchanged.

The reopened Figma mobile artboard confirms that the original hero is not a plain radial wash: it contains a dark, low-contrast technical interface/network visual under a strong but not opaque dark overlay. The reference keeps a recognizable central rectangular dashboard silhouette and green node/connection signals behind the centered title. The next pass must recover the original Figma image layer rather than use the earlier generated substitute.

The public Figma canvas bootstrap did not expose a directly downloadable original image-resource URL through its loaded resource list. The asset must therefore be recovered from the rendered Figma artboard itself, with the non-background interface/text layers excluded, rather than substituted with a generic generated network visual.

At 101% Figma canvas zoom, the mobile frame shows the needed original composition clearly: a central dark rectangular dashboard silhouette, **CONNECT WITH VERTEX** microcopy, a lime action rectangle, and network paths concentrated toward the upper-right and lower-left behind the centered Contact title. The recovery reference will be cropped from this rendered original frame and used only to remove foreground typography; the remaining technical composition should be retained.
