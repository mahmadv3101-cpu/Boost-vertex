# Notifications and Messages Panel — Figma Reference Notes

The supplied reference is a `320 × 1622` dark full-height panel. It opens independently from the dashboard and presents Notifications first, followed by Messages.

## Top panel structure

| Element | Reference treatment |
|---|---|
| Panel | Full-height near-black canvas, 320px wide, with no card radius or outer whitespace. |
| Notifications header | Lime outline bell at left, `Notifications` in white Chivo-style heading text, and a compact olive-lime `3 New` count pill aligned right. |
| Notification section | 55px divider beneath the header; four stacked notification rows with a 31–33px colored circular icon, bold white title, muted gray multiline description, then subdued timestamp. |
| Notification colors | Blue people/lead icon; deep-green check; olive-lime chart; charcoal backup/download icon. The last row is visibly muted/read. |
| Section divider | A long horizontal divider around y=518 separates the notification block from Messages. |
| Messages header | Lime outline mail icon, `Messages` heading in white, and lime `View All` action aligned right. |

## Message-list structure

Each message uses an approximately 94–110px row with a sender name and date on one line, then subject, a two-line muted preview, optional deep-blue `Unread` tag, and a bottom divider. The visible message records are Jane Cooper / Partnership Inquiry / May 20 / Unread; Esther Howard / SEO Services Question / May 19; and Devon Lane / Project Discussion / May 18 / Unread. Descriptions and metadata use Inter-style compact text while section and item titles use Chivo-style stronger typography.
